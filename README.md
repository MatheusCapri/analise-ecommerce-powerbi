# Análise de E-commerce com Power BI

Projeto desenvolvido com o objetivo de analisar o desempenho de um e-commerce e gerar insights para apoiar a tomada de decisão e crescimento do negócio.

---

## Objetivo

Construir um dashboard gerencial para monitorar vendas, perfil de clientes e identificar oportunidades de crescimento no e-commerce.

A análise busca responder perguntas como:

* Quais canais geram mais vendas?
* Qual o comportamento dos clientes?
* Existe padrão de faturamento ao longo do tempo?
* Onde estão as oportunidades de crescimento?

---

##  Base de Dados

O projeto utiliza duas bases principais:

* **Base de Compras:** informações de vendas (valor, data, canal, departamento)
* **Base de Clientes:** dados demográficos (idade, renda, localização)

---

##  Ferramentas Utilizadas

* Power BI (modelagem e visualização)
* Excel (base de dados)

---

## Estrutura do Dashboard

O projeto foi dividido em duas visões principais:

###  Visão de Vendas

Principais métricas:

* Quantidade de vendas: **55,8 mil**
* Receita total (sem frete): **72,6 milhões**
* Receita total (com frete): **72,9 milhões** 

Análises realizadas:

* Evolução das vendas ao longo do tempo
* Receita por canal de venda (Internet, Mobile, Aplicativo)
* Comparação entre faturamento com e sem frete

---

###  Visão do Cliente

Principais métricas:

* Total de clientes: **17 mil**
* Média de renda: **8,2 mil** 

Análises realizadas:

* Distribuição de idade dos clientes
* Distribuição de renda (faixas)
* Segmentação por estado

---

##  Principais Insights

* Canais digitais concentram a maior parte das vendas
* Existe concentração de clientes em determinadas faixas de renda
* O faturamento apresenta variação ao longo do tempo (potencial de sazonalidade)
* Diferença entre vendas com e sem frete é pequena → impacto logístico controlado

---

## Diferenciais do Projeto

* Estruturação em duas visões (cliente e vendas)
* Uso de filtros interativos (estado, canal, renda, idade)
* Criação de métricas relevantes para negócio
* Foco em storytelling com dados
